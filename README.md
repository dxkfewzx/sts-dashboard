# STS Dashboard

ระบบจัดการคลังอุปกรณ์ไอที ที่พัฒนาด้วย React และเชื่อมต่อกับ Supabase เป็นฐานข้อมูล backend

## คุณสมบัติหลัก
- แสดงภาพรวมสต็อกสินค้าคงคลัง (Dashboard)
- จัดการรายการสินค้าคงคลัง (เพิ่ม/แก้ไข/ลบ)
- จัดการหมายเลขเครื่องของสินค้า (เพิ่ม/แก้ไข/ลบ)
- จัดการประวัติการแจ้งซ่อมอุปกรณ์
- แสดงรายงานสถิติสรุป
- รองรับการทำงานบนอุปกรณ์เคลื่อนที่ (Responsive Design)
- ใช้ไลบรารี Bootstrap 5, ฟอนต์ Prompt, SweetAlert2 เช่นเดียวกับระบบเดิม

## สเกลงานและขอบเขตการพัฒนา
งานพัฒนาในโฟลเดอร์ `sts-dashboard` ประกอบด้วย:

### 1. การแปลงระบบจาก HTML/JavaScript เป็น React Application
- ย้ายจากระบบที่ใช้ HTML, CSS, JavaScript พร้อม localStorage ไปเป็น React 19 พร้อม hooks (useState, useEffect)
- แยกองค์ประกอบเป็น components ที่ใช้ซ้ำได้ (Sidebar, DashboardContent, InventoryList, Details, Report, RepairDetails, WithdrawModal)

### 2. การเปลี่ยนฐานข้อมูลจาก localStorage เป็น Supabase
- แทนที่การเก็บข้อมูลใน localStorage ด้วยฐานข้อมูล PostgreSQL ผ่าน Supabase
- เชื่อมต่อกับตาราง: `inventory_items`, `serial_numbers`, `repair_records`
- ใช้ Supabase client สำหรับการดำเนินการ INSERT, UPDATE, DELETE

### 3. การเพิ่มฟังก์ชันและปรับปรุง UI/UX ตามคำขอผู้ใช้
- **เพิ่มฟังก์ชันเพิ่มหมายเลขเครื่องแบบจำนวนมาก** (ในหน้า Details.js): เพิ่มความสามารถในการเพิ่มหมายเลขเครื่องหลายรายการพร้อมกันผ่าน textarea
- **แก้ไขปัญหา modal เบิกอุปกรณ์ไม่แสดงผล**: แก้ไข WithdrawModal.js ให้แสดงผลอย่างถูกต้องเมื่อกดปุ่ม
- **ปรับปรุงการออกแบบให้ responsive**: อัปเดต App.css ให้เหมาะกับทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ
- **ปรับปรุง UI ของ modal เบิกอุปกรณ์**: 
  - จัดเรียงฟอร์มใหม่ให้เป็นระเบียบด้วย Bootstrap Grid (row g-4, col-md-*)
  - ปรับขนาดฟอร์มคอนโทรลให้เหมาะกับการใช้งาน (ลบฟอร์มขนาดใหญ่พิเศษออก)
  - จัดกลุ่มฟิลด์ที่เกี่ยวข้องให้อยู่ในแถวเดียวกันเพื่อการใช้งานที่ดีขึ้น
  - ปรับขนาด modal ให้เหมาะสม (ลดจาก modal-xl เป็นขนาดมาตรณะ)
  - ปรับขนาดปุ่ม "ยืนยันการเบิกอุปกรณ์" ให้เล็กลงและเหมาะสม (py-2 px-4 → py-1 px-3, rounded-3 → rounded-2)
  - ลดระยะห่างภายใน modal body (p-5 → p-3) เพื่อความกระชับ

### 4. การแก้ไขปัญหาการนำทาง
- แก้ไข href ใน InventoryList.js จาก `/details.html?id=` เป็น `/details/` เพื่อให้ทำงานกับ React Router ได้อย่างถูกต้อง

│  │  ├─ InventoryList.js

│  │  ├─ RepairDetails.js
│  │  └─ WithdrawModal.js
│  ├─ App.js              # จุดเข้าใช้งานหลักพร้อมการนำทาง
│  ├─ App.css             # สไตล์ที่เหมือนเดิมจาก HTML ต้นฉบับ

## การติดตั้งและรันโปรเจกต์

### ขั้นตอนที่ 1: ติดตั้งการพึ่งพา
เปิด Terminal และไปที่โฟลเดอร์ `sts-dashboard` แล้วรันคำสั่ง:
```bash
npm install
```

### ขั้นตอนที่ 2: รันเซิร์ฟเวอร์พัฒนา
หลังจากติดตั้งการพึ่งพาเสร็จแล้ว ให้รัน:
```bash
npm start
```
เซิร์ฟเวอร์จะทำงานที่ `http://localhost:3000` เปิดเบราว์เซอร์และไปที่ URL นี้เพื่อใช้งานแอปพลิเคชัน

### ขั้นตอนที่ 3: สร้างไฟล์สำหรับ production (ตัวเลือก)
หากต้องการสร้างไฟล์ที่พร้อมสำหรับการ deploy ให้รัน:
```bash
npm run build
```
ไฟล์ที่สร้างจะอยู่ในโฟลเดอร์ `build/`

## การตั้งค่า Supabase
แอปพลิเคชันนี้เชื่อมต่อกับ Supabase โดยใช้ URL และคีย์ที่กำหนดไว้ในไฟล์ `src/App.js` (และถูกส่งผ่านไปยังองค์ประกอบต่างๆ ผ่าน props) คุณไม่จำเป็นต้องตั้งค่าเพิ่มเติมหากต้องการใช้งานกับฐานข้อมูลที่ตั้งค่าไว้แล้ว

หากต้องการเปลี่ยนไปใช้โปรเจกต์ Supabase ของคุณเอง ให้แก้ไขค่าต่อไปนี้ใน `src/App.js`:
```javascript
const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

## การทำงานของแอปพลิเคชัน
1. **หน้าหลัก (Dashboard)** - แสดงภาพรวมสต็อกสินค้า จำนวนทั้งหมด จำนวนที่เบิกออก และจำนวนคงเหลือ พร้อมปุ่ม "เบิกอุปกรณ์"
2. **รายการสินค้า** - เข้าถึงได้จากเมนูด้านข้างหรือโดยตรงที่ `/inventory` เพื่อเพิ่ม แก้ไข ลบ รายการสินค้า
3. **รายละเอียดสินค้า** - คลิกที่ไอคอนตาในรายการสินค้าหรือแดชบอร์ด เพื่อดูและจัดการหมายเลขเครื่องของสินค้านั้น
4. **รายงาน** - เข้าถึงได้จากเมนูด้านข้างหรือโดยตรงที่ `/report` เพื่อดูสถิติสรุปและตารางรายการซ่อม
5. **ประวัติการแจ้งซ่อม** - เข้าถึงได้จากเมนูด้านข้างหรือโดยตรงที่ `/repair` เพื่อเพิ่ม แก้ไข ลบ รายการแจ้งซ่อม
6. **เบิกอุปกรณ์** - คลิกปุ่ม "เบิกอุปกรณ์" ในแดชบอร์ด เลือกรายการ เลือกหมายเลขเครื่องที่พร้อมใช้งาน (status = Available) กรอกข้อมูลการเบิก (เลข Job, ชื่อผู้เบิก, แผนก, อาคาร, ชั้น) แล้วบันทึก

## หมายเหตุ
- แอปพลิเคชันนี้ออกแบบให้ทำงานได้ทันทีโดยไม่ต้องตั้งค่าเพิ่มเติม หากคุณต้องการใช้งานกับฐานข้อมูลท้องถิ่นของคุณเอง ให้ตรวจสอบและอัปเดตการตั้งค่า Supabase ตามที่อธิบายข้างต้น
- สำหรับการใช้งานในระบบผลิต แนะนำให้เปิดใช้งาน Row Level Security (RLS) ใน Supabase และสร้างนโยบายการเข้าถึงที่เหมาะสม
- ไฟล์ `workflow.md` ในโฟลเดอร์นี้สรุปขั้นตอนการพัฒนาและเปรียบเทียบกับระบบเดิมที่ใช้ HTML + localStorage
